# Автопилот продвижения — MVP

Это **тестовая версия** агента, отдельно от основного сайта. Пока она **не публикует сообщения**, если не заданы защищённые настройки Telegram.

## Что есть
- `promo/60/index.html`: минутный эксперимент, субъективная оценка до и после, кнопка «Поделиться», переход к Лаборатории.
- `promo/queue.json`: пять предварительно подготовленных постов.
- `promo/publish.py`: публикация следующего поста в Telegram, без внешних Python-зависимостей.
- `promo/state.json`: учёт уже отправленных постов.
- `.github/workflows/promo-autopilot.yml`: расписание по понедельникам, средам и пятницам в 06:17 UTC, ручной запуск с предварительным просмотром.

## Запуск и ограничения
1. Сначала проверить страницу и ручной запуск с опцией `dry_run=true`.
2. Добавить в Settings → Secrets and variables → Actions секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Бот должен быть администратором канала с правом публикации. **Никогда не вставляйте токен в репозиторий или в публичный чат.**
3. После проверки объединить ветку с `main`. GitHub Actions запускает расписание из ветки по умолчанию; до объединения расписание не действует.
4. После объединения проверить GitHub Pages и опубликовать одно тестовое сообщение с разрешения владельца.

При отсутствии секретов программа печатает предпросмотр и **не отмечает публикацию как выполненную**. Повторы по очереди прекращаются, когда все пять постов отправлены.

## Следующая итерация
Подключение аналитики в рамках согласованной политики конфиденциальности; проверка реальных переходов и прохождений; тестирование заголовков. Облачная генерация ИИ ещё **не подключена**. Текущий агент — автоматизация готовых постов, а не автономная языковая модель.

Чтобы не нарушать приватность, текущий эксперимент не отправляет оценки пользователя на сервер.
